# 2026.10.0 — 2026-10-02

A security update. The collector image is smaller and no longer carries known, fixable vulnerabilities. This is a drop-in upgrade.

## FIXED

- **Security fixes in the image you run** `Deployment` — The previous image carried 29 known high-severity security issues. Most were in build tools that were never meant to ship, and the rest were in the underlying operating system. They are all gone in this release.
- **Security fixes in the collector's network libraries** `Collector` — Updated the components the collector uses to talk to Sense and to your database, closing six published vulnerabilities.

## CHANGED

- **The compose file is now named compose.yml** `Deployment` — If you start the stacks with make, or with docker compose and a profile, nothing changes. Only a command that names the old file explicitly needs updating.

## IMPROVED

- **Reliability** `Collector` — Behind-the-scenes work on the automated checks. Nothing to do.

______________________________________________________________________

## Before you upgrade

Nothing to do. No settings, database or dashboard changes, and nothing to migrate. Pull the new image and restart.

Still not supported: Sense accounts with multi-factor authentication enabled. Tracked as issue [#8](https://github.com/luxardolabs/sense-collector/issues/8).

Surfaces used above: `Collector` (the running collector — what it reads, writes and logs) and `Deployment` (the image and the stacks you run to operate it).
