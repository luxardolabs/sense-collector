# 2026.11.1 — 2026-11-15

A security update for the collector image, and safer dashboards for the development stacks.

The labels after each item are this collector's surfaces: `Collector` (the running service), `Dashboards` (the bundled Grafana) and `Docs`.

## IMPROVED

- **Development dashboards reached by name** `Dashboards` — The development stacks now run on a shared development host and their dashboards are reached by name there, no longer on a local port.
- **Start each prod stack the same way** `Docs` — The second monitor's prod stack has its own start, stop, log and status commands, matching the first.
- **Clearer setup docs** `Docs` — The docs say which settings file each development stack reads, and which dashboard passwords are refused.

## FIXED

- **Security update** `Collector` — The image carries the latest operating-system security fixes, including two for its compression library.
- **Dashboard sign-in can't fall back to the default** `Dashboards` — A development dashboard refuses to start without a real admin password, and the password you set is the one in force every time it starts, even on an older installation or after you change it.
