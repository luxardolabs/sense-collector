## Features

- Dev stacks on the dev host (SENSECOLLE-130): the Makefile declares `DEV_HOST := devhost` (an ssh alias), read by the image block v27's `dev-pin`/`smoke`. The repo's own dev targets (`up`, `down`, `restart`, `logs`, `ps`, `shell`, `dev-*`, `bb-*`) reach `DOCKER_HOST=ssh://$(DEV_HOST)` and resolve from `.env.dev`, as `dev-deploy` does; `dev-up`/`bb-up`/`up` start the pinned image and build nothing.
- Dev Grafana guard (SENSECOLLE-130, SENSECOLLE-134): both dev Grafanas start through `ops/grafana/dev-entrypoint.sh` (bind-mounted read-only). It refuses an empty or whitespace-only `GRAFANA_PASSWORD`, `admin` and the `.env.example` placeholder (any case) and a password holding a line break; pipes the password to `grafana cli admin reset-admin-password --password-from-stdin` on every start (Grafana applies `GF_SECURITY_ADMIN_PASSWORD` only on DB creation); then `exec /run.sh`. The compose entrypoint refuses when the script is not a mounted file.
