## Schema / Migrations

None (InfluxDB, no migrations). Field-type changes, all additive in effect:

- **sense_always_on.yearly_cost** is now a float in dollars (÷ YEARLY_COST_DIVISOR), was raw integer cents. A shard group that already holds the integer field refuses the float until it rolls over (≤ 7 days, owner-accepted). Both dev buckets hold no sense_always_on fields (read-only SHOW FIELD KEYS), so dev is unaffected.
- **sense_always_on_comparison**: cohort_avg_w pinned float, count/display_count pinned int.
- **Realtime readings** (sense_mains hertz/watts/voltage, device watts and sd\_\*) always written as float (a932389); these were float in every captured payload.
- **sense_mains.hertz** is omitted when the monitor sends no hz (6d1fa9e).
- sense_event points are written at millisecond precision when Sense gives an ISO time (22eaf58).

## Fixes

- Auth pacing: one login per renewal under a lock, exponential backoff on failure (capped at AUTH_RETRY_MAX_DELAY), a REST 401 re-logs in only for the token it was sent with, a login 429's Retry-After honoured, the WebSocket re-login paced the same way, the backoff exponent overflow fixed (084354f, 175b7ec, 7d4f9d9, 38d1c16).
- Logins read every field (and refuse an empty token / null monitor id) before replacing any (a79a1c7, 4883f75).
- Retry-After parsed, clamped to API_RETRY_AFTER_MAX, interruptible by shutdown (a520f4d).
- Secrets: startup log shows only `<set>`/`<unset>`; URLs logged without userinfo; any `@` in the InfluxDB/API/WS URLs refused; hpack/h2 records dropped at the root handler; redactor escapes C1, U+2028/9 and lone surrogates (38a9b07, 4ca52c2, 71f58de, 4883f75, e8d577d, a945e48, 214c924).
- Storage: an unwritable point is set aside alone; a 422 partial write counts only its dropped points; malformed device entries skipped; backslash-ending names kept; queued timeline events drained on close; the queue processor finishes its batch on close; a device detail is cached only after InfluxDB accepted it, and a cache hit no longer re-writes it (4f8afdd, 22eaf58, d0bdfa1, 07fa8b2, 4883f75).
- Device queue no longer spins on unnamed always-on devices (33370d0).
- Exports: 0600 files (existing ones too), 0700 folder, names one-to-one with device ids (percent-encoded, hashed when long), devices.json / received_data.jsonl names (30382bf, ade8ce3).
- Health: heartbeat path agreed by both processes; touched only for a realtime frame with usable mains, judged before the write (the sink never decides health); hello/state frames no longer count; frames without hz accepted; one plug's unreadable current no longer loses the frame; healthcheck reads HEALTH_CHECK_MAX_AGE like the collector (8d4d902, c060d05, b3929e4, 9df40e2, 6d1fa9e, 4883f75).
- WebSocket: non-object frames ignored; close bounded by WS_CLOSE_TIMEOUT (3a8de0d).
- Config: out-of-range numbers clamp to the nearest bound and name the setting; heartbeat throttle capped at half the max age (438c234, 4883f75).
- always_on yearly_cost in the device unit; comparison field types pinned; numeric-string yearly_cost converted; oversized values kept out of int64 (544f663, 2ed8688).
