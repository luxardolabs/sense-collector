## Fixes

- **CVE-2026-69244, CVE-2026-69243, CVE-2026-59881 (aiohttp, floor `>=3.14.3`)** — aiohttp is the transport for every InfluxDB write. Out-of-bounds heap read in the C response parser while building an error message for a malformed response; request smuggling via WebSocket upgrades; client decompressing RSV1 frames with `permessage-deflate` never negotiated. Both packages were transitive with unbounded upper ranges, so a plain re-lock resolved back to the vulnerable versions — the floor has to be declared in our own manifest.
- **CVE-2026-71554 (h2, floor `>=4.4.1`)** — duplicate `Host` headers forwarded to the consumer, enabling smuggling where HTTP/2 is downgraded to HTTP/1.1. h2 is the HTTP/2 stack behind the Sense API client.
- **Health check DST bug** — `app/health/check.py` computed heartbeat age as `datetime.now() - datetime.fromtimestamp(mtime)`, both naive and container-local. Across a DST transition this shifts by an hour, so a live collector could report unhealthy or a stale one healthy. Both sides are now aware UTC.
- **Naive datetimes** in `websocket.py` (reconnect ETA) and `main.py` (startup banner) — now `datetime.now(UTC).astimezone()`: created aware, converted to the container zone only for display.
- **`app/core/config.py` logged through the root logger** (6 sites), so those records bypassed the per-area levels (`LOG_LEVEL_GENERAL`/`_API`/`_STORAGE`) and could not be filtered by source. Now a module logger.
- `harness/fake_sense.py` was first-party code the lint gate had never scanned; covering it surfaced 17 real mypy errors, including a heterogeneous dict literal inferring `object` for a float field so the load arithmetic was unchecked. Now a `TypedDict`; mypy clean.
