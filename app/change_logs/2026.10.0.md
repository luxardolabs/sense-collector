# 2026.10.0 — 2026-10-02

A security and hygiene release. The runtime image is rebuilt so it no longer carries the build toolchain, and two transitive CVE floors are added. The guards move from luxarch 0.190.0 to 0.249.1. No config or data-shape changes; no migrations.

## Issues Closed

- **SENSECOLLE-46** — The shipped image carried 29 fixable HIGH/CRITICAL CVEs, because the runtime stage leaked poetry, its deps and pip. Found by luxaudit 0.11's new image leg, scanning `:2026.09.1`. Fixed in 922d076 (see Fixes); this release is what clears it, since the image leg scans the published `:VERSION`.
- **SENSECOLLE-45** — `make test` failed confusingly ("no coverage % on STDIN") when the test image had been pruned, because the stamp file outlived the image. A `_test-image-present` prerequisite now drops the stamp when the image is genuinely gone. (e2bce9c)

Still open, did **not** ship: **SENSECOLLE-35** (MFA/TOTP auth, GitHub issue #8).

## Infra / Ops

- **Runtime image hardened** (SENSECOLLE-46). Poetry is installed into `/opt/poetry` in the builder rather than system site-packages, so the base stage's site-packages copy carries only the 27 app distributions. The runtime stage runs `apt-get upgrade -y` and removes pip, which the app never uses and which vendors its own urllib3/msgpack/setuptools. Before: 29 fixable HIGH/CRITICAL (20 OS, 9 Python). After: 0, measured with luxaudit 0.12.0's baked Trivy on the rebuilt `--target base`.
- **Guard pins: luxarch 0.190.0 → 0.249.1, luxlint 0.55.0 → 0.60.1, luxaudit 0.9.0 → 0.12.0**, across two refreshes (e2bce9c, 922d076) plus docs-only patches picked up at release. Every applicable red was fixed rather than deferred:
  - `gitleaks` adopts the v8 asset. The scanner is pinned and mirrored instead of `ghcr.io/gitleaks/gitleaks:latest`, the config goes to a per-run mktemp file, and an identity pass refuses non-fleet author/committer addresses. History is clean.
  - `buildx-setup` refuses stray per-project builders. It reads builder names from `buildx ls --format json`, because the `{{.Name}}` form also prints node names (`luxardo-builder0`) and would false-refuse.
  - `make status` passes `LUXARCH_STATUS_WRITE=1`.
  - `E2E_IMAGE` carried 3 trailing spaces from an inline comment (an invalid docker reference); the comment is moved above the assignment.
  - `guard-upgrade` verifies its own write, and carries its asset marker.
  - ruff, mypy, types-aiofiles and types-python-dateutil are dropped from the dev group (guard-owned; luxlint runs them mount-only). The lock went from 45 to 37 packages; nothing else moved version.
  - Claude-Code hooks re-emitted (two new: `luxpm-search-before-create`, `no-github-issues`). The fleet skills `/wrap-up`, `/pin-bump` and `/escalate` are added, `/release` is re-emitted with its marker, and the fleet conduct pointer is added to CLAUDE.md. (c5798dd)
- **Transitive security floors** in pyproject, following the existing aiohttp/h2 pattern:
  - `anyio >= 4.14.2` — CVE-2026-63374 / -64847 / -63349. Under httpx → httpcore, on the Sense API path. Locked at 4.15.1. (e2bce9c)
  - `urllib3 >= 2.8.0` — CVE-2026-97687 / -97688 / -97689. Inside influxdb-client, and verified loaded on the async write path. (922d076)

## Fixes

- **The release image no longer ships the build toolchain** (SENSECOLLE-46): poetry, virtualenv, msgpack, setuptools, pip, and an un-upgraded Debian layer (perl-base ×3 CRITICAL, openssl, pcre2, gzip, sqlite).
- **`make test` recovers from a pruned test image** instead of failing at the coverage ratchet (SENSECOLLE-45).

## Notes

**Pre-deploy:** none. **Post-deploy:** none — no config, env-var or data-shape change, and no migration. Restart the stacks onto the new image.

Running compose by hand: the file is now `compose.yml`. `docker compose --profile …` discovers it automatically; only an explicit `-f compose.yaml` needs updating.

Verified before tagging: lint, mypy, honest and arch green (luxarch 55 passed, 0 failed); `make test` 207 passed, coverage 78% at the floor; `make test-e2e` passes.
